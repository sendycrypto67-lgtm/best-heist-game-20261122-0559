The Halcyon Heist is a top-down stealth heist game: cross the museum gallery unseen, steal the Halcyon Diamond past patrolling guards and sweeping cameras, and slip out before the alarm meter fills.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Move with WASD or arrows, hold Shift to sneak, click to toss a coin, press E to grab the diamond, reach the green exit.
